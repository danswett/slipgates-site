Install

  1. Download the installer for your PC. Not sure which? Open Settings > System > About and look at "System type": "x64-based processor" means the Intel or AMD installer, "ARM-based processor" means the Arm64 one.
  2. Run it. Windows shows a blue box, Windows protected your PC. This is expected: the beta installer is not signed yet. Click More info, then Run anyway.
  3. Slipgates opens. Under Agents on this machine, choose Install CLI for any coding tool you don't have yet, then Set up for each agent you use. Sign in to each CLI yourself.
