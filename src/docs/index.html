Getting started

Beta

What {{name}} is

{{name}} lets you keep an eye on your AI coding sessions (Copilot CLI, Claude Code, Codex) from your phone. When a session needs you, a notification on your PC and a card on your phone say so, and you can answer its questions, approve or deny what it wants to do, or stop it from wherever you are.

Install on Windows

  1. Get the newest beta from GitHub Releases and download the installer for your PC:
    • Intel or AMD (most PCs): the installer without "arm64" in its name
    • Windows on Arm (Snapdragon and similar): the installer with "arm64" in its name
    Not sure? Open Settings > System > About and look at "System type". "x64-based processor" means the first file; "ARM-based processor" means the second.
  2. Run it. Windows shows a blue box, Windows protected your PC. This is expected: the beta installer is not signed yet, and Windows warns about any installer it does not recognize. Click More info, then Run anyway.
  3. {{name}} opens. In Settings, the Agents on this machine section shows whether your coding tools are ready and offers Set up or Repair for the hooks. If a coding CLI is missing, choose Install CLI and {{name}} installs it with Windows Package Manager after you confirm; some need extra Windows components and may ask for administrator approval. Then choose Set up to connect its hooks. {{name}} doesn't sign you in to the CLI or trust your project folder; do those in the CLI yourself. If Set up can't make an agent ready, tell us which step it stopped at. The app keeps itself up to date and offers Restart to update when there is a newer version.

Connect your phone

  1. On your PC, open {{name}} > Settings and, under Your devices, choose Sign in with GitHub. It shows a code and a GitHub link.
  2. On your phone, open the phone app and choose Sign in with GitHub. Open the GitHub link it shows, enter the code, and use the same GitHub account as your PC.
  3. Return to the phone app. Your PC's sessions appear there.

Known issues

  • The installer is unsigned, so Windows warns as described above.
  • On Windows on Arm, use the Arm installer. The Intel/AMD one runs there but we haven't tested it.
  • See the list of open bugs for the rest.

Getting help

For help today, reply privately in the email or Teams conversation your invitation came in. Send only the minimum needed. Remove names, paths, prompts, code, tokens and sign-in codes, and review any screenshot or log before sending it. Do not post support content or personal information in public GitHub issues. If something fails, tell us the first step that failed. If it all worked, tell us that too: a PC session showing on your phone is the end of this guide.

What the beta collects is on the Privacy page.

Uninstall

Settings > Apps > Installed apps > {{name}} > Uninstall. This stops the background service and removes what {{name}} added: its scheduled task, its hooks in your CLIs and its install folder. It never removes a CLI or signs you out of an account. Your project files are untouched.

Uninstalling does not itself erase server or support records; use the privacy contact on the Privacy page for those. Your profile (device key, account, settings and logs) stays in %LOCALAPPDATA%\AgentBridge, so a reinstall picks up where you left off. To remove it too, close {{name}}, uninstall, then delete that folder.
