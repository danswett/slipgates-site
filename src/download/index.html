Which installer?

Open Settings > System > About and look at "System type".

  • x64-based processor (Intel or AMD, most PCs): AgentBridgeApp-win-Setup.exe
  • ARM-based processor (Windows on Arm, such as Snapdragon): AgentBridgeApp-win-arm64-Setup.exe

The installer files are named AgentBridgeApp, but the app itself is called {{name}}.

Before you run it

The beta installer is not signed yet, so Windows shows a blue box, Windows protected your PC. This is expected. Click More info, then Run anyway.
